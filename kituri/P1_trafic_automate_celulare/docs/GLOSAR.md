# Glosar român–englez

Termenii pe care îi veți întâlni în articole și în documentație, cu traducerea folosită în kit. În raport folosiți termenul românesc, cu cel englezesc între paranteze la prima apariție dacă nu e evident.

## Termeni specifici temei

| Română | Engleză | Pe scurt |
|---|---|---|
| automat celular | cellular automaton | grilă de celule cu stări discrete, actualizate după reguli locale |
| actualizare paralelă | parallel (synchronous) update | toate celulele se actualizează simultan, pe baza stării vechi |
| condiții la limită periodice | periodic boundary conditions | inel: ce iese pe o parte intră pe cealaltă |
| frontieră deschisă | open boundary | vehiculele intră și ies din sistem |
| diagrama fundamentală | fundamental diagram | fluxul în funcție de densitate |
| densitate critică | critical density | densitatea la care fluxul e maxim |
| flux, debit | flow, throughput | vehicule pe unitatea de timp care trec printr-un punct |
| ambuteiaj spontan | phantom jam | ambuteiaj apărut fără obstacol, din fluctuații |
| diagrama spațiu-timp | space-time diagram | pozițiile vehiculelor în timp |
| încetinire aleatoare | random slowdown (dawdling) | regula 3 din NaSch |
| VDR | velocity-dependent randomization | probabilitate de încetinire mai mare pentru vehiculele oprite |
| slow-to-start | slow-to-start rule | pornire întârziată după oprire |
| stare metastabilă | metastable state | stare care durează, dar se prăbușește la o perturbare |
| detector de buclă | induction loop (E1) | detectorul SUMO care numără vehiculele într-un punct |
| limită de viteză variabilă | variable speed limit | control prin schimbarea vitezei maxime pe tronson |

## Termeni comuni

| Română | Engleză | Pe scurt |
|---|---|---|
| sistem autoadaptiv | self-adaptive system | sistem care își schimbă singur comportamentul în timp ce rulează, pe baza a ceea ce măsoară |
| buclă MAPE-K | MAPE-K loop | Monitor, Analyze, Plan, Execute peste o bază de cunoștințe comună (Kephart și Chess, 2003) |
| sistem gestionat | managed system | partea care face treaba propriu-zisă; controllerul o observă prin senzori și o modifică prin efectori |
| histerezis | hysteresis | praguri diferite la intrarea și la ieșirea dintr-o stare, ca să evitați oscilațiile |
| variantă de referință | baseline | varianta fără adaptare cu care se compară controllerul |
| rulare, sămânță | run, seed | o execuție completă a unui scenariu; seed-ul fixează numerele aleatoare |
| abatere standard | standard deviation | cât variază rezultatele între rulări (cu ddof=1) |
| interval de încredere | confidence interval | intervalul în care se află probabil media reală |
| mărimea efectului | effect size | cât de mare e diferența, independent de semnificație; aici A12 |
| perioadă de încălzire | warm-up period | începutul simulării, exclus din metrici |
