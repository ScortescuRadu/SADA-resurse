# Glosar român–englez

Termenii pe care îi veți întâlni în articole și în documentație, cu traducerea folosită în kit. În raport folosiți termenul românesc, cu cel englezesc între paranteze la prima apariție dacă nu e evident.

## Termeni specifici temei

| Română | Engleză | Pe scurt |
|---|---|---|
| problema rucsacului | knapsack problem | alegerea unui subset de valoare maximă în limita unei capacități |
| funcție de fitness | fitness function | valoarea unui individ, cu tratarea constrângerilor |
| penalizare | penalty | scăderea fitness-ului proporțional cu încălcarea constrângerii |
| reparare | repair | transformarea unei soluții nefezabile într-una fezabilă |
| selecție prin turnir | tournament selection | câștigă cel mai bun dintre k indivizi aleși la întâmplare |
| încrucișare uniformă | uniform crossover | fiecare genă vine de la un părinte ales aleator |
| mutație prin inversarea bitului | bit-flip mutation | fiecare bit se inversează cu o probabilitate |
| elitism | elitism | cei mai buni trec neschimbați în generația următoare |
| optimizare dinamică | dynamic optimization | problema se schimbă în timpul căutării |
| santinelă | sentinel (detector) individual | individ reevaluat periodic ca să detecteze schimbarea |
| hipermutație | hypermutation | creșterea temporară a ratei de mutație după o schimbare |
| imigranți aleatori | random immigrants | indivizi aleatori introduși pentru diversitate |
| front Pareto | Pareto front | soluțiile pe care nu le domină nicio altă soluție |
| hipervolum | hypervolume | volumul dominat de front față de un punct de referință |
| evaluare | fitness evaluation | un calcul al funcției obiectiv; unitatea de cost pentru comparații |

## Termeni comuni

| Română | Engleză | Pe scurt |
|---|---|---|
| sistem autoadaptiv | self-adaptive system | sistem care își schimbă singur comportamentul în timp ce rulează, pe baza a ceea ce măsoară |
| buclă MAPE-K | MAPE-K loop | Monitor, Analyze, Plan, Execute peste o bază de cunoștințe comună (Kephart și Chess, 2003) |
| sistem gestionat | managed system | partea care face treaba propriu-zisă; controllerul o observă prin senzori și o modifică prin efectori |
| histerezis | hysteresis | praguri diferite la intrarea și la ieșirea dintr-o stare, ca să evitați oscilațiile |
| variantă de referință | baseline | varianta fără adaptare cu care se compară controllerul |
| rulare, sămânță | run, seed | o execuție completă a unui scenariu; seed-ul fixează numerele aleatoare |
| abatere standard | standard deviation | cât variază rezultatele între rulări (cu ddof=1) |
| interval de încredere | confidence interval | intervalul în care se află probabil media reală |
| mărimea efectului | effect size | cât de mare e diferența, independent de semnificație; aici A12 |
| perioadă de încălzire | warm-up period | începutul simulării, exclus din metrici |
